Battle City
Ретро-игра "Танки" 
Автор: Косенкова Екатерина (ekaterina.minty@gmail.com)

Описание: Программа представляет собой интерактивную 2D-аркаду, вдохновленную классической игрой Battle City. 
Включает в себя игровой интерфейс, искусственный интеллект врагов со стратегиями поведения, систему разрушаемых поверхностей, 
систему бонусов и прокачки оружия.

Требования:
* Python версии выше 3.10 и ниже 3.14
* Сторонняя библиотека Pygame (установка: pip install -r requirements.txt)

Состав:
* Точка входа (консольный интерфейс): main.py
* Пакет с основной логикой программы: src/
   * Инициализация пакета: __init__.py
   * Константы (размеры, цвета, типы клеток, настройки баланса): settings.py
   * Карты четырёх уровней: levels.py
   * Игровые объекты (блоки, пули, танки игрока и врагов, бонусы): sprites.py
   * Игровой цикл, правила игры и отрисовка: game.py
* Тесты: tests/

Справка по запуску: --help или -h
Запуск программы выполняется командой: py main.py
Запуск тестов: py -m pytest

Управление:
 
* Стрелки или WASD - движение
* Пробел - выстрел
* ENTER - старт в меню
* 1, 2, 3, 4 - перейти на нужный уровень (для отладки)
* R - начать заново после победы или поражения

Подробности реализации:
* Всё, что нарисовано на экране и двигается, описано в модуле src/sprites.py. 
* Базовый класс Tank отвечает за столкновения, эффекты (горение, неуязвимость) и выстрел, от него наследуются PlayerTank и EnemyTank. 
* Параметры вражеских танков хранятся в словаре ENEMY_STATS. 
* Класс EnemyTank содержит поведение врага: метод choose_direction выбирает направление по стратегии, sees_player решает, 
пора ли стрелять, heal лечит бронированный танк, get_speed учитывает усиление от других танков. 
* Класс Bullet двигает пулю и передаёт блоку урон через Block.take_damage. Класс Bonus хранит тип бонуса, 
а метод apply применяет его к игроку. 
* Карты уровней лежат в src/levels.py в виде матриц из констант TILE_*. 
* Класс Game в модуле src/game.py хранит группы спрайтов и состояние игры (menu, playing, game_over, win). 
* Метод load_level строит уровень, spawn_enemy создаёт врагов, check_bullets обрабатывает попадания, check_win_lose 
проверяет победу и поражение, а draw рисует кадр. 
* Модуль main.py разбирает аргументы командной строки и запускает Game.
* Ошибки выводятся одной строкой без Traceback (полный Traceback с ключом --debug).
